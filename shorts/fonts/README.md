# 폰트 폴더

이 폴더에 `.otf` 또는 `.ttf` 파일을 넣으면 **설치 없이** 자막에 쓰입니다.
설정 파일의 `font:` 항목보다는 뒤, 시스템 설치 폰트보다는 앞선 순위입니다.

## 추천: Pretendard

https://github.com/orioncactus/pretendard/releases 에서
`Pretendard-1.3.9.zip` 을 받아 `Pretendard-ExtraBold.otf` 를 여기에 넣으세요.

자막은 굵을수록 배경과 잘 분리됩니다. 파일이 여러 개면
**ExtraBold → Bold → SemiBold** 순으로 자동 선택합니다.

라이선스는 SIL Open Font License 1.1 이라 상업적 이용과 영상 삽입이 자유롭습니다.

# shorts — 숏폼 영상 자동 렌더러

설정 파일 하나로 **클립 연결 · 자막 · BGM · 메타데이터 제거**까지 한 번에 처리합니다.
당근·인스타 릴스·유튜브 쇼츠용 세로 영상을 매번 같은 톤으로 뽑는 것이 목적입니다.

## 왜 쓰나

- **GPS가 자동으로 지워집니다.** 아이폰 원본에는 오차 30m 수준의 촬영 위치가 박혀 있습니다.
  이 도구는 모든 단계에서 메타데이터를 제거하므로 빠뜨릴 수가 없습니다.
- **톤이 항상 일정합니다.** 자막 폰트·외곽선·전환·음량이 매번 같습니다.
- **BGM 저작권 걱정이 없습니다.** 외부 음원을 쓰지 않고 직접 합성합니다.
- 두 벌이 나옵니다 — BGM 포함본, 그리고 앱 내장 음원을 쓸 무음악본.

영상 하나를 만드는 순서와 자막 쓰는 법은 **[WORKFLOW.md](WORKFLOW.md)** 에 정리했습니다.

## 설치

ffmpeg가 필요합니다.

```bash
# macOS
brew install ffmpeg
# Windows
winget install Gyan.FFmpeg
# Linux
sudo apt install ffmpeg
```

```bash
pip install -r requirements.txt
```

### 폰트 (권장: Pretendard)

자막은 굵은 폰트일수록 배경과 잘 분리되어 읽힙니다. **Pretendard ExtraBold** 를 권합니다.

1. https://github.com/orioncactus/pretendard/releases 에서 zip 내려받기
2. 압축을 풀고 `Pretendard-ExtraBold.otf` 를 이 프로젝트의 `fonts/` 폴더에 넣기

설치할 필요 없이 폴더에 넣기만 하면 됩니다. 라이선스가 SIL OFL 1.1 이라
상업적 이용과 영상 삽입이 자유롭습니다.

폰트를 고르는 순서는 이렇습니다.

1. 설정 파일의 `font:` 경로
2. 프로젝트 `fonts/` 폴더 (여러 개면 ExtraBold → Bold → SemiBold 순)
3. 시스템에 설치된 폰트 (Pretendard → 맑은 고딕/나눔고딕 순)

셋 다 없으면 오류 메시지에 해결 방법이 나옵니다.

## 사용법 1 — 대시보드 (권장)

**Windows** — `start.bat` 더블클릭
**macOS** — `start.command` 더블클릭

처음 실행하면 가상환경을 만들고 필요한 라이브러리를 설치한 뒤 브라우저를 엽니다.
두 번째부터는 바로 열립니다.

터미널에서 직접 실행하려면:

```bash
python app.py
```

브라우저가 자동으로 열립니다 (`http://127.0.0.1:8765`). 설정 파일을 손으로 쓸 필요가 없습니다.

- 영상을 끌어다 놓으면 `clips/` 에 들어갑니다
- 클립을 체크해 순서를 정하고, 재생하면서 **현재 위치에 자막 추가**
- 자막 위치·크기를 슬라이더로 맞추면 화면에 바로 반영됩니다
- **구간 지정**으로 쓸 범위를 정합니다. 얼굴이 나온 부분을 뺄 때 씁니다
- 지정한 구간은 **끄고 켤 수 있습니다** — 클립별 `이 구간만 사용` 체크박스,
  또는 오른쪽 `구간 지정 적용하기` 스위치로 전체를 한 번에. 값은 그대로 남아 있어
  "뺀 버전"과 "안 뺀 버전"을 번갈아 뽑아 비교하기 좋습니다
- BGM은 미리듣기로 고르고, 크기와 더킹을 조절합니다
- **렌더링**을 누르면 진행 상황이 보이고, 끝나면 결과를 바로 재생합니다

화면에서 바꾼 내용은 `config.yaml` 로 저장되므로, 다음에 명령줄로 다시 뽑을 수도 있습니다.

옵션: `python app.py --port 9000 --no-browser --project /다른/폴더`

### 폰·태블릿에서 쓰기

PC 에서 대시보드를 켜두고, 같은 와이파이의 폰에서 접속해 작업할 수 있습니다.
영상도 폰 사진첩에서 바로 올릴 수 있어 옮기는 수고가 없습니다.

**Windows** — `start.bat` 을 만든 뒤 아래처럼 실행하거나, 바로 가기를 만들어 인자를 넣으세요.

```
start.bat --lan
```

**직접 실행**

```bash
python app.py --lan
```

터미널에 QR 이 뜹니다. 폰 카메라로 찍으면 바로 열립니다.

- 렌더링은 **PC 가 합니다.** 폰은 화면만 보여주므로 배터리·성능과 무관합니다
- 접속 주소에는 일회용 열쇠가 붙습니다. **링크를 아는 기기만** 들어올 수 있고,
  같은 와이파이라도 주소만으로는 접속되지 않습니다
- 열쇠는 실행할 때마다 새로 만들어지고, 창을 닫으면 접속도 끊깁니다
- `--lan` 없이 실행하면 그 컴퓨터에서만 열립니다(기본값)

> 아이폰 영상은 HEVC 코덱이라 브라우저가 직접 읽지 못합니다. 그래서 미리보기용 사본을
> `.cache/` 에 만듭니다. 첫 클립을 열 때 몇 초 걸리고 그 뒤로는 즉시 열립니다.
>
> 브라우저가 재생할 수 있는 형식을 자동으로 고릅니다 — H.264(mp4)가 되면 그쪽을,
> 안 되면 WebM(VP8)으로 만듭니다. 고른 형식이 실패해도 다른 형식으로 한 번 더
> 시도하므로, 어떤 브라우저에서도 미리보기가 나옵니다.

## 설치 없이 쓰기 — 포터블 묶음

Python·ffmpeg 를 폴더 안에 넣어, **아무것도 설치되지 않은 컴퓨터에서도** 압축만
풀면 바로 쓸 수 있는 묶음을 만듭니다. 클라우드에 올려두고 여러 컴퓨터에서
쓰기 좋습니다.

만들 때 (Windows 에서 한 번만):

```powershell
powershell -ExecutionPolicy Bypass -File make_portable.ps1
```

인터넷에서 약 120MB 를 받아 `..\shorts-portable\` 폴더와 `.zip` 을 만듭니다.
완성된 폴더는 약 200MB 입니다.

쓸 때: 압축을 풀고 **`실행.bat`** 더블클릭. 설치 과정이 없습니다.

### 압축·전송할 때 주의

- **`.venv` 폴더는 절대 넣지 마세요.** 만든 컴퓨터의 경로가 박혀 있어 다른
  컴퓨터에서 깨집니다. 포터블 묶음은 `.venv` 대신 `runtime\python` 을 씁니다.
- **`clips`, `out` 폴더를 비우고 압축하세요.** 아이 영상이 클라우드에 올라갑니다.
- ALZ 보다 **ZIP** 을 쓰세요. 윈도우가 기본으로 풀 수 있고 다른 OS 에서도 열립니다.

## 사용법 2 — 명령줄

```bash
python build.py config.yaml
python build.py config.yaml -o 결과폴더    # 산출물 위치 지정
```

산출물 (기본 `out/` 폴더):

| 파일 | 용도 |
|---|---|
| `<output>.mp4` | BGM 포함. 바로 업로드 |
| `<output>_nomusic.mp4` | 무음악. 앱 내장 음원 쓸 때 |
| `<output>_thumb.jpg` | 썸네일 |

## 설정 파일

```yaml
output: 놀이터_효녀        # 산출물 이름

music:
  style: cheerful         # cheerful | calm | playful | none
  bpm: 122                # 생략 시 스타일 기본값
  volume: 0.42            # 0~1. 현장음 대비 BGM 크기
  duck: true              # 현장음이 커지면 BGM을 자동으로 낮춤

audio:
  keep_original: true     # 현장음 유지 (false면 BGM만)
  loudness: -14           # 최종 라우드니스(LUFS). 숏폼 표준

clips:
  - file: clips/IMG_6380.MOV
    captions:
      - {text: "우리집 아기 놀이터 출근 완료", at: [0.3, 3.8]}
      - {text: "시소는 아직 연구 중입니다",   at: [8.5, 12.5]}

  - file: clips/IMG_6381.MOV
    trim: [0.5, 4.0]        # 이 구간만 사용 (생략 가능)
    captions:
      - {text: "엄마 운동 부족이야",  at: [0.2, 4.1], y: 0.72, size: 60}
      - {text: "효녀의 특별 PT 시작", at: [0.6, 4.1], y: 0.79, size: 60}
```

`file` 경로는 **설정 파일 위치 기준**입니다.

`trim` 을 쓰면 자막의 `at` 시각은 **잘라낸 뒤 기준**입니다. `trim: [0.5, 4.0]` 에
`at: [0, 2]` 면 원본 0.5~2.5초 구간에 자막이 나옵니다.

### 자막 항목

| 키 | 기본값 | 설명 |
|---|---|---|
| `text` | 필수 | 자막 내용 |
| `at` | 필수 | `[시작초, 끝초]` — **해당 클립 안에서의** 시각 |
| `y` | `0.80` | 세로 위치 (0=맨 위, 1=맨 아래) |
| `size` | `56` | 글자 크기 |
| `fade` | `0.4` | 나타나고 사라지는 시간(초) |

### 전체 옵션

| 키 | 기본값 | 설명 |
|---|---|---|
| `size` | `[1080, 1920]` | 출력 해상도 |
| `fps` | `30` | 프레임레이트 |
| `transition` | `0.4` | 클립 사이 크로스페이드(초) |
| `fade_in` / `fade_out` | `0.5` | 시작·끝 페이드 |
| `thumbnail_at` | 자동 | 썸네일 시각(초). 생략 시 전체의 55% 지점 |
| `crf` | `23` | 화질 (낮을수록 고화질·큰 용량) |
| `font` | 자동 | 한글 폰트 경로 |

클립별 옵션으로 `trim: [시작초, 끝초]` 를 넣으면 그 구간만 사용합니다.

## BGM만 따로 뽑기

```bash
python bgm.py --list                                   # 스타일 목록
python bgm.py --style calm --duration 45 --out bgm.wav
```

| 스타일 | 분위기 |
|---|---|
| `cheerful` | 마림바 + 우쿨렐레. 밝고 통통 튀는 육아 브이로그 톤 |
| `calm` | 벨 + 패드. 드럼 없이 잔잔한 감성 톤 |
| `playful` | 피치카토 + 우드블록. 장난스럽고 빠른 톤 |
